# 📱 EduControl Pro - Android APK

## APK olish usullari

### 1. GitHub Releases (Eng oson)
1. [Releases](../../releases) sahifasiga boring
2. Eng so'nggi versiyani toping
3. `EduControl-Pro.apk` ni yuklab oling
4. Telefonizga o'rnating

### 2. GitHub Actions (Har bir push dan keyin)
1. [Actions](../../actions) sahifasiga boring
2. "Build Android APK" workflow ni tanlang
3. Oxirgi muvaffaqiyatli build ni oching
4. "Artifacts" bo'limidan APK yuklab oling

## Telefonizga o'rnatish

1. APK faylni telefoningizga yuboring (Telegram, USB, yoki boshqa usul)
2. Faylni oching
3. "Unknown sources" (Noma'lum manbalar) ga ruxsat bering
4. O'rnating!

## Texnik ma'lumotlar
- **Package Name:** `uz.eduprocrm.app`
- **Min Android Version:** 5.0 (API 21)
- **Target Android Version:** 14 (API 34)

## Muammolar

Agar o'rnatishda muammo bo'lsa:
1. Telefoningiz sozlamalaridan "Noma'lum manbalardan o'rnatish" ga ruxsat bering
2. Antivirus dasturni vaqtincha o'chiring
3. Play Protect ogohlantirishini e'tiborsiz qoldiring (bu bizning ilovamiz)
