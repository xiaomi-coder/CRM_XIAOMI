# EduControl Pro - Online CRM

Ta'lim markazlari uchun zamonaviy CRM tizimi. O'quvchilar, guruhlar, davomat, to'lovlar va moliyaviy hisobotlarni boshqarish.

## 🚀 Online Deploy Qilish

To'liq qo'llanma: **[DEPLOYMENT.md](DEPLOYMENT.md)**

### Qisqacha:
1. **Supabase** - Database yaratish va `supabase-schema.sql` ni ishga tushirish
2. **Environment Variables** - `.env.production` faylini to'ldirish
3. **Deploy** - Vercel yoki Netlify orqali deploy qilish

---

## 💻 Local Ishga Tushirish

**Prerequisites:** Node.js v18+

1. Dependencies o'rnatish:
   ```bash
   npm install
   ```

2. `.env.local` faylida `GEMINI_API_KEY` ni sozlang

3. Loyihani ishga tushirish:
   ```bash
   npm run dev
   ```
